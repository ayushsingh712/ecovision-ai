# Local dataset directory

This directory is generated by the pipeline and is not tracked by git.

- `raw/` — downloaded RealWaste archive and images
- `processed/` — 256×256 JPEG cache
- `manifest.csv` — every image with label, split, hashes, and group id
- `splits.json` — split statistics, class weights, and reproducibility metadata
- `INSPECTION.json` — raw dataset audit
- `PREPARE_REPORT.json` — preprocessing audit

Download and prepare with:

```bash
make download
make prepare
```
