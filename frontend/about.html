Inside EcoVision AI

Two PyTorch models, one leakage-aware dataset split, and an explanation layer you can inspect. This page documents exactly what was trained and what it cannot do.

How a prediction is made

An uploaded image is validated by content type and size, decoded with Pillow, corrected for EXIF orientation, converted to RGB, and center-cropped to 224×224. Pixel values are normalized with ImageNet statistics because one of the models was initialized from ImageNet weights.

The network produces seven logits. A softmax turns them into probabilities, the highest is reported as the prediction, and the top three are shown so you can see when the model is uncertain. For the predicted class, Grad-CAM backpropagates the class score into the last convolutional stage and produces a coarse heatmap of influential regions.

Recycling guidance is not generated by the model. It comes from a maintained JSON guide that maps each class to a typical bin, preparation steps, cautions, and environmental context. That separation keeps disposal advice reviewable.

Architectures

A baseline and a transfer-learning model

Both models share the same class order, preprocessing, and evaluation protocol, so the comparison is meaningful.

Baseline

Custom CNN

Four convolutional blocks (32 → 64 → 128 → 256 filters), each with two 3×3 convolutions, batch normalization, ReLU, and max pooling. Global average pooling, dropout 0.4, and a linear classification head.

— parameters 224×224 input
  • Trained from random initialization
  • Class-weighted loss and label smoothing
  • Shows what is achievable without pretrained features
Transfer learning

MobileNetV2

ImageNet-pretrained MobileNetV2 with a new dropout + linear head. Stage A trains only the head with the backbone frozen; stage B fine-tunes the final three inverted-residual blocks with a lower learning rate.

— parameters Depthwise separable
  • Designed for efficient CPU inference
  • Batch-norm statistics kept frozen while fine-tuning
  • Final model selected on validation macro-F1

Methodology

Built to avoid misleading numbers

Leakage-aware splits

Exact duplicates are removed by SHA-256. Perceptual dHash similarity groups near-duplicate frames, and whole groups are assigned to one split. The split is 70/15/15 per class with a fixed seed.

Augmentation, not memorization

Random resized crops, horizontal flips, small rotations, colour jitter, and light random erasing are applied only to training images. Validation and test use a deterministic center crop.

Macro-F1 selection

Classes are imbalanced (420 to 921 images). Training uses capped inverse-frequency class weights, and the best checkpoint is selected on validation macro-F1 rather than plain accuracy.

Test split used once

The held-out test split is evaluated only after training. It is never used for tuning, early stopping, or model selection.

Limitations

What this model cannot do

  • Trained on landfill photography from a single Australian facility, so accuracy may drop on household photos, different lighting, or other regions.
  • The seven target classes are coarser than the nine RealWaste classes; Textile Trash is merged into General waste.
  • Assumes one dominant waste item per image and does not detect or localize multiple objects.
  • Recycling guidance is general and may not match local municipal rules, bin colours, or acceptance lists.
  • Feedback is stored unverified and is not used for automatic retraining.
Do not rely on this tool for hazardous waste, medical waste, batteries, or e-waste. Follow local authority guidance for those materials.

Future work

Planned improvements are documented rather than quietly implied: multi-object detection with bounding boxes, an admin review workflow for feedback, periodic retraining with a versioned dataset snapshot, per-class calibration, and localized recycling guidance with jurisdiction-aware rules.

Recycling guide version —. The model version and checkpoint stage are reported by the API and shown throughout the interface so a development checkpoint is never presented as a final model.
